# Security Policy

## Supported Versions

| Version | Supported |
| ------- | :-------: |
| 1.x | ✅ |
| < 1.0 | ❌ |

## Reporting a Vulnerability

If you discover a security issue in MergeMind, please **do not open a public GitHub issue**.

Instead, report it privately by email:

**dineshbista642@gmail.com**

Please include:

- A description of the issue
- Steps to reproduce it
- The affected version (if known)
- Any suggested fix or mitigation

## Response

We aim to:

- Acknowledge your report within **48 hours**
- Investigate and confirm the issue within **7 days**
- Release a fix as quickly as possible

We'll keep you updated throughout the process.

## Scope

This policy covers:

- MergeMind web application
- MergeMind backend API
- MergeMind GitHub repository

Third-party services (such as GitHub or Google AI) follow their own security policies.

## Responsible Disclosure

Please give us reasonable time to investigate and fix the issue before publicly disclosing it.

Thank you for helping keep MergeMind secure.
